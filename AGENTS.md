# Istruzioni di progetto

- Rispondi in italiano, in breve. Limita gli aggiornamenti a risultati, problemi o decisioni utili.
- Per le modifiche, lavora sul codice ed esegui solo i controlli indispensabili e mirati. Non ripetere verifiche gia superate senza una nuova modifica o un problema concreto.
- Esegui build complete, crea installer e installa o aggiorna l'app solo quando l'utente lo chiede esplicitamente per il lavoro corrente. Una richiesta precedente non autorizza a ripeterli per ogni modifica successiva.
- Accumula le modifiche richieste e crea un solo installer alla fine, se richiesto.
- Non verificare archivi, registrazioni, modelli o dati personali salvo richiesta esplicita. Non includere dati personali o trascrizioni nei commit del codice.
- Non usare computer use, screenshot o controllo dell'interfaccia salvo richiesta esplicita; preferisci file, shell e strumenti mirati.
- Non ampliare il lavoro con controlli estesi, test completi o attivita accessorie non necessari alla richiesta. Non creare agenti aggiuntivi salvo richiesta esplicita.
- Procedi autonomamente nelle operazioni gia autorizzate, senza chiedere conferme ripetute.
